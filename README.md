# 🦅 Tomi Zárate — Portfolio

Portfolio personal de **Tomás "Tomi" Zárate**, diseñador gráfico.

## Stack

- HTML5 + CSS3 + JavaScript (vanilla)
- Sin frameworks ni dependencias externas
- Hosting: GitHub Pages

## Paleta

| Color | Hex | Uso |
|-------|-----|-----|
| Negro | `#000000` | Fondo |
| Off-white | `#F5F5F5` | Texto |
| Blanco | `#FFFFFF` | Títulos |
| Rosa pastel | `#FFC5D3` | Detalles, acentos, hover |

## Estructura

```
portfolio/
├── index.html          # Página principal
├── css/
│   └── style.css       # Estilos
├── js/
│   └── main.js         # Interactividad
├── assets/
│   ├── images/         # Tus imágenes aquí
│   └── videos/         # Tus animaciones aquí
└── README.md           # Este archivo
```

## Cómo agregar proyectos

1. Subí tus imágenes/videos a `assets/images/` o `assets/videos/`
2. Decime el nombre y yo actualizo el HTML
3. O si preferís, editás `index.html` y cambiás los placeholders
